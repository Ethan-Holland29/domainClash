# Domain Expansion videos (bundled fallback)

The easy way to add a Domain Expansion video is in the app: the
**"Domain Expansion videos"** panel has one row per domain - drop an mp4 onto
it or click **Choose file**. Those videos are saved in your browser.

This folder is an optional fallback that is bundled into the build. A file
here is used only when no video was added for that domain in the panel.
Name it after the character (`sukuna.mp4`) or the domain gesture id
(`malevolent-shrine.mp4`); `default.mp4` covers every domain.

Only add clips you have the right to use; files here are bundled into the build.

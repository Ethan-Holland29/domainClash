# Sound effects & voice lines (optional replacements)

Every sound in DomainClash has a synthesised placeholder, so this folder can
stay empty. Drop a file here to replace one; no code changes needed.

Sound effects - name the file after the sound id:

`primary-cast`, `secondary-charge`, `secondary-release`, `impact-light`,
`impact-heavy`, `blocked`, `guard-up`, `player-hurt`, `opponent-windup`,
`domain-ready`, `domain-cast`, `domain-collapse`, `on-cooldown`, `not-ready`, `victory`, `defeat`

e.g. `impact-heavy.mp3`

Voice lines (otherwise spoken with text-to-speech) - `voice-<character>-<slot>`:

e.g. `voice-sukuna-primary.mp3`, `voice-gojo-secondary.mp3`,
`voice-megumi-ultimate.mp3`

`.mp3`, `.wav`, `.ogg` and `.m4a` work. Only add audio you have the right to use.
